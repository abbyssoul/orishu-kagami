# orishu-monitor

`orishu-monitor` is the interactive terminal operator client for Orishu. It is
currently an experimental placeholder; use `orishuctl` for implemented cluster
administration.

From the repository root:

```sh
make build
make run-monitor
```

Kagami is the graphical experiment-authoring and scientific-visualization
client. `orishu-monitor` remains focused on cluster operations.

See the [project architecture](../../docs/architecture.md) and root
[README](../../README.md).
