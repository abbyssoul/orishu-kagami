This directory is intentionally kept in the repository for `cargo-deb`.

`orishu-worker` uses `maintainer-scripts = "debian"` in
[`Cargo.toml`](../Cargo.toml). `cargo-deb` only generates the Debian
systemd maintainer scripts when that directory exists.

The directory is currently empty because the package relies on
`cargo-deb`'s autogenerated systemd install/enable scripts rather than
custom maintainer script files.
